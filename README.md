# AlfaGen: Privacy Gateway — модуль безопасности персональных данных

FastAPI-прокси между бизнес-системой и LLM для безопасного взаимодействия. Маскирует 17 категорий ПДН перед отправкой в модель и восстанавливает исходные значения после ответа.

## Проблема

Бизнес-системы используют LLM, но в запросах утекают ПДН: ФИО, телефоны, email, паспорта, адреса. Законодательство и требования ЦБ запрещают передавать такие данные внешним моделям.
Разные команды решают задачу по-своему: решения несовместимы, дублируются, их тяжело переиспользовать. Если демаскирование не реализовано полностью — ответ модели теряет смысл.

## Решение

FastAPI-прокси между системой-потребителем и LLM. Единый endpoint `/process` — точка входа для всех систем.

- Первый запрос с `payload_id` → маскирование + сохранение соответствия.
- Второй запрос с тем же `payload_id` → демаскирование + возврат оригинала.
- Ответ всегда в формате `{"result": "..."}` — простой контракт, легко интегрировать.
- Никаких открытых ПДН в LLM — уходит только токенизированный текст.

Ключевой принцип: данные не покидают защищённый контур в открытом виде. LLM видит токены — клиент получает реальные значения.

## Архитектура

1. Система-потребитель отправляет запрос с данными (возможно, содержащими ПДН).
2. Модуль защиты ПДН:
   - авторизует систему;
   - выбирает политику;
   - детектит ПДН;
   - токенизирует;
   - сохраняет соответствия в зашифрованном TTL-хранилище.
3. Безопасный запрос (без ПДН) уходит в LLM.
4. Ответ модели возвращается, демаскируется и отдаётся клиенту.

## Покрытие

Все 17 обязательных категорий ПДН:

1. ФИО
2. Дата рождения
3. Место рождения
4. Паспорт РФ (серия/номер)
5. Гражданство
6. Орган выдачи паспорта
7. Код подразделения
8. Дата выдачи паспорта
9. Водительское удостоверение
10. Адрес
11. Email
12. Телефон
13. ИНН
14. Номер карты
15. CVV
16. PIN
17. Имя держателя карты

Дополнительно: загранпаспорт, свидетельство о рождении.

## Устойчивость к вариациям

- Регистр: иванов, ИВАНОВ, Иванов.
- Форматы дат: 21.03.1990, 1990-03-21, 03.21.1990, 21 марта 1990 года.
- Даты прописью: двадцать первое марта 1990 года.
- Обфускации: test @ example.org, 1234 5678.
- Разделяющие слова: серия 45 09 номер 123456.
- Контекстные ловушки:
  - «Поэт Александр Пушкин» — не маскируется.
  - «Адрес отделения банка» — не маскируется.
  - «Клиент Александр Пушкин, паспорт…» — маскируется.

## Технологии

- Python
- FastAPI
- LLM (адаптер AlfaGen)
- SQLite (WAL) для хранения соответствий
- Docker
- Prometheus (метрики)
- JSON-логи (аудит)


## Статус

Развиваемый прототип. Работают базовые правила всех 17 обязательных категорий и двух дополнительных документов, токенизация, точное обратное преобразование неизменённого текста, авторизация систем, зашифрованные соответствия с TTL и локальный.

По умолчанию сетевых вызовов LLM нет; адаптер AlfaGen включается явно после настройки ключа.
